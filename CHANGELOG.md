# Changelog

## v0.4.3-preview

- Packaged as a Windows desktop app window instead of opening a normal browser by default.
- Added title GIF under the app name.
- Added Warcraft Logs report loading, fight selection, and timeline generation.
- Added dungeon and boss detection from WCL pulls.
- Added Overview and Detail timeline modes.
- Added health lines, damage taken heat, healing heat, and death markers.
- Added support for boss skills, healing cooldowns, defensives, items, and potions.
- Added MRT note export.
- Added in-app Config panel for adding, deleting, importing, exporting, restoring, and syncing config entries.
- Added Chinese and English UI.
- Added one-click development launcher and PowerShell build script.
