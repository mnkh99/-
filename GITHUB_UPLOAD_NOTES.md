# GitHub Upload Notes

Upload the contents of this `github_ready` folder as the repository root.

Recommended files to commit:

- `README.md`
- `CHANGELOG.md`
- `.gitignore`
- `requirements.txt`
- `app.py`
- `index.html`
- `config.yaml`
- `title.gif`
- `start_app.bat`
- `build_one_click.ps1`

Do not commit:

- `token.txt`
- `config.yaml.bak`
- `build/`
- `dist/`
- generated `.exe`
- generated `.zip`

If you want to share a ready-to-use package, upload the zip file under GitHub Releases instead of committing it to the source repository.
